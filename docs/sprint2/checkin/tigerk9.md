What is one thing you learned about the codebase or about software engineering practice?
- I learned about “Depot” which is what the upstream repository uses to run CI tests. Essentially Depot is a cloud based CI runner that runs extremely fast. It saves the developers a lot of time not having to wait for CI tests to fully run (it can take a while), but it costs money (through tokens) so we’re not able to access their depot. I also learned that with CI testing, you can run the CI test as if the code were running on a Linux machine, that way if you have one developer working on Mac and another on Windows, their operating system won’t interfere with the running of the checks. This ensures that the code works regardless of the operating system and hardware.
